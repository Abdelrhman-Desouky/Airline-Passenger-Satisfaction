# Airline Passenger Satisfaction Classification

## Overview
This project applies supervised machine learning techniques to classify airline 
passenger satisfaction levels based on service-related features. The goal is to 
predict whether a passenger is satisfied or not, using a binary classification 
approach on a real-world dataset.

## Dataset
The project uses the **Airline Passenger Satisfaction** dataset (European airline data), 
publicly available on Kaggle:
[Airline Passenger Satisfaction Dataset](https://www.kaggle.com/datasets/teejmahal20/airline-passenger-satisfaction)

## Machine Learning Models
Four classification models were implemented and compared to identify the 
best-performing approach:
- **Logistic Regression**
- **Decision Tree Classifier**
- **Support Vector Classifier (SVC)**
- **Random Forest Classifier**

## Workflow
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training and evaluation
- Performance comparison across the four models
